# *ДЗ №1*: Создание телефонного справочника

## Запуск

> Для корректной работы приложения требуется версия *Python* *>=3.12*

Приложение реализовано в одном файле `phone_book.py`. Для запуска необходимо подать его на вход интерпретатору *Python*:

```shell
python phone_book.py
```

При работе в *Linux shell* достаточно запустить скрипт напрямую как исполняемый файл:

```shell
./phone_book.py
```

## Функции

По умолчанию загружается пример телефонного справочника из файла `phone_book.json`, который расположен в одной директории со скриптом `phone_book.py`

После запуска приложения отображается меню, через которое доступны функции приложения, а также приглашение, через которое выбирается требуемый пункт меню:

```text
Телефонный справочник [phone_book.json] (10)
--------------------------------------------
(1): Открыть из файла
(2): Сохранить в файл
(3): Показать все контакты
(4): Создать контакт
(5): Найти контакт
(6): Изменить контакт
(7): Удалить контакт
(8): Выход

>
```

В приложении реализованы все функции, запрошенные в задании.

### Особенности реализации

- Работа с контактами осуществляется в копии телефонного справочника, хранящейся в памяти. Сохранение изменений в файл необходимо выполнять явно, через соответствующую команду меню.

- Перед выходом предлагается сохранить телефонную книгу в файл, если в неё были внесены изменения.

- Ошибочный ввод (напр. несуществующий пункт меню и т.п.) как правило приводит к возврату в основное меню без дополнительной диагностики.

- В некоторых случаях пустой ввод является подтверждением использования текущего значения поля, которое также отображается в приглашении (например, для команды изменения существующего контакта).

- Поиск по полям контактов выполняется самым простым образом: через поиск подстроки с помощью метода [`str.find()`](https://docs.python.org/3/library/stdtypes.html#str.find).
